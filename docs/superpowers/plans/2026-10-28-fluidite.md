# Clair Ferme : animation et parcours fluides
> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Donner du temps à la scène d'ouverture et rendre les actions existantes plus directes, en conservant le vert et les données.
**Architecture:** JavaScript natif et CSS existants. Réutiliser la scène SVG et Pia, sans bibliothèque ni ressource externe. Navigation interne avec retour, position de défilement et focus.
**Tech Stack:** JavaScript ES modules, CSS, Playwright 1.56.1.
**Spec:** demandes de la conversation : Pia descend, ferme progressive, vague lente, profondeur, boutons utiles.

## Global Constraints
- Conserver la palette verte/crème, la clé clair.ferme.v2 et le moteur financier.
- Ouverture complète environ 4 secondes ; ignorable après préparation ; réduction des mouvements respectée.
- Ne pas multiplier les actions principales : utiliser les commandes existantes et un retour contextuel.
- Ce lot porte sur animation et ergonomie ; authentification/synchronisation est un sous-projet distinct.

## Review Focus
- Démarrage lent/échoué : ne pas révéler une app non prête ; conserver Réessayer.
- Réduction des animations : ouvrir sans attente imposée, relecture accessible.
- Navigation/retour : retrouver le défilement et rendre le focus utilisable.
- Aucun stock : permettre d'acheter directement au lieu d'une impasse.
- Modale soumise/annulée : ne pas conserver un ancien écran ou doubler une sauvegarde.
